An editorial-grade, modern luxury real estate platform built for **Mexus Agency**, a private client brokerage connecting discerning buyers, sellers, and investors with exclusive on- and off-market residential estates, commercial developments, and prime land across **Mexico and the United States**.

Designed and engineered as a showcase web application for high-performance portfolio presentation.

---

## ✨ Key Features & UX Highlights

- **🏆 Luxury Editorial Aesthetic**:
  - Custom typography pairing of *Cormorant Garamond* (editorial serif) and *Manrope* (clean geometric sans).
  - Deep Obsidian Pine (`#09211a`), Champagne Gold (`#b6925c`), and Alabaster Cream palette.
  - Ambient glassmorphism sticky navigation bar with backdrop blur.

- **💱 Dynamic Cross-Border Currency Switcher**:
  - Live toggle between **Mexican Pesos (MXN)** and **US Dollars (USD)** with real-time price calculations across all cards, listings, and detail views.

- **🔍 Instant Live Search & Category Filtering**:
  - Zero-lag real-time keyword search across titles, locations, and descriptions.
  - Multi-category filtering: *Residential Houses*, *Land & Acreage*, *Commercial & Mixed-Use*.
  - Dynamic result counter and responsive empty state with 1-click filter reset.

- **🖼️ Interactive Property Showcase & Modal Gallery**:
  - High-resolution imagery with hover zoom micro-interactions.
  - Rich dialog modal featuring dual-currency pricing, architectural specs grid (dimensions, bedrooms, bathrooms, type, availability), and full property briefs.
  - Accessible modal with keyboard navigation (`Esc` to close), backdrop click dismissal, and scroll locking.

- **🔗 Web Share API & Clipboard Integration**:
  - One-touch property sharing via native mobile share or automatic clipboard copy with animated toast confirmation alerts.

- **👥 Dedicated Team & Market Advisory**:
  - Comprehensive leadership profiles for *Aidi Lopez* (Founder & Director), *Gus Duran* (Mexico Specialist), and *Marc Palmer* (US Market Director) with direct WhatsApp, telephone, and email routing.
  - 4-Stage client acquisition journey (*Brief → Due Diligence → Negotiation → Notary Closing*).

- **📱 100% Responsive & Accessible**:
  - Mobile slide-out drawer with animated hamburger toggle.
  - High-contrast compliance, semantic HTML5 landmarks, and fluid clamp typography.

---

## 🛠️ Technology Stack

- **Frontend**: Semantic HTML5, Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Glassmorphism, Fluid Typography), Vanilla JavaScript (ES6+).
- **Icons & Typography**: Google Fonts (*Cormorant Garamond*, *Manrope*).
- **Architecture**: Single-Page Application (SPA) architecture with hash routing support and zero external npm dependencies.

## 🚀 How to Run & Deploy to GitHub Pages

### 1. Run Locally
Simply clone or download this repository and double-click `index.html` in any modern web browser. No local web server or build step is required!

### 2. Deploy to GitHub Pages in 30 Seconds
1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "feat: Initial commit - Mexus Agency luxury real estate platform"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/mexus-agency.git
   git push -u origin main
   ```
2. In your GitHub repository, navigate to **Settings** → **Pages**.
3. Under **Build and deployment** → **Branch**, select `main` and `/ (root)`.
4. Click **Save**. Your website will be live at `https://YOUR_USERNAME.github.io/mexus-agency/`!
